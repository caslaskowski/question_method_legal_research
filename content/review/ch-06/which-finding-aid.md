Sort each situation by the route Chapter 6 gives it. Searching the full text is the last resort, not the first.

::: {.try kind="sort" title="Reach the statute" bins="Retrieve by citation | Popular Name Table | Subject index | Full-text search"}
- A secondary source cites 42 U.S.C. § 12112 **Retrieve by citation**
    - Known source, known address. Pull it in the annotated code.
- You know it is called the Americans with Disabilities Act **Popular Name Table**
    - The Popular Name Table maps common names to code locations. Often the fastest route when you know the name but not the title and section.
- You know the subject (organic labeling) and the jurisdiction, nothing else **Subject index**
    - The code’s own index leads to the chapter; then scan the table of contents for the definitions section.
- You need every section that uses a distinctive phrase, across the whole code **Full-text search**
    - When the question is about a phrase rather than a subject, a search within the code is the right tool, and the only one that finds every use.
- A case quotes a statute and gives its section number **Retrieve by citation**
    - Then read it in the code yourself: the operative text, the definitions, the exceptions, the cross-references.
- Your client says “the lemon law” **Popular Name Table**
    - A nickname is a popular name. The table turns it into a citation.
:::
