Chapter 16 review · Drill

Excerpt Triage

Forty-five minutes of exam time is the whole cycle at compression. Arrange the moves.

The compressed cycle (Put it in order)

Top is first.

  1. Read every provided source before writing a word
    • Starting to write first is how examinees miss the one authority that controls.
  2. Build a map of what each source provides, and which binds and which persuades
    • Excerpt triage: the mental map, with the hierarchy applied.
  3. Name the ambiguity the item was built around and note whether the provided cases resolve it
    • The exam usually hides an undefined term or a scope question.
  4. State the macro question and break it into the research questions the materials must answer
    • The method’s first move, compressed.
  5. Answer each question from the source the triage identified, and apply the controlling authority to the facts
    • Dispositive facts compared to the client’s.
  6. Make the sufficiency call: the materials answer it, or name the gap and what would fill it
    • Closure, committed, is the step examinees forget.
